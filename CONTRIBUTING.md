# Contributing

Thank you for taking an interest in Fetch Terminal. It is a small project
looked after by one person, and every report helps.

## Code changes

Fetch Terminal does not take code changes through pull requests. That is
simply how the project is set up, and it is nothing to do with the quality of
what you wrote. A change made elsewhere has to be understood, tested and kept
up by one person for years, so it is more reliable to make each one in the
same hands.

What helps most is a description. Open an issue and tell us:

- what you did, step by step;
- what you expected to happen;
- what happened instead;
- your Fetch Terminal version (shown in the sidebar) and your Linux
  distribution and desktop.

A screenshot is worth a lot. If you have an idea for a feature, say what you
are trying to get done, not only what you would like the button to look like.

## Security problems

Please do not open a public issue for a security problem. Use the private
route described in [SECURITY.md](./SECURITY.md) instead.

## Forking

The code is free software under the GNU General Public Licence, version 3 or
later, so you are welcome to fork it and take it in your own direction. The
[LICENSE](./LICENSE) file has the terms.

## Questions

Questions are welcome as issues too. Every one gets read.
